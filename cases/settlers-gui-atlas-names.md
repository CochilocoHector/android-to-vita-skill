# 案例：GUI 图集名匹配（菜单/HUD 空白）

## 现象

主菜单只有文字，没有背景；进入游戏没有 HUD 图标；暂停菜单空白。

## 初始假设

- GUI 根本没有被绘制
- SWF 文件缺位图
- 纹理上传失败

## 静态证据

- `CGUIManager::draw()` 每帧转发到 `RenderFX::Render()`（[ASM]）
- 运行时两个字段有效（[LOG] `+0x24=0x... +0x28=1`）
- SWF 的 5 个位图标签只有 7 字节占位头（[BYTES]）
- 图集由 `LoadTextures` 遍历纹理表后按名字加载（[ASM]）
- 名字比较是 `strstr(请求名, 表内名字)`（[ASM] PLT → strstr）
- 960 表内容带 `_960` 后缀，请求名不带（[LOG]）

## 排除的错误假设

| 假设 | 排除依据 |
|---|---|
| GUI 没被绘制 | 每帧调用且字段有效 |
| SWF 里没有位图 | 有位图标签，只是占位；真实图集外部加载 |
| 纹理上传失败 | `texture4` 已正确上传 |

## 根因

`strstr("./texture0.pvr", "texture0_960.pvr")` 永不命中 →
所有带后缀的图集被判定"不需要加载" → 菜单/HUD 空白。

## 最小修复

只在比较时去掉 `_960`/`_854` 后缀；注册名、路径、分组保持不变。
复制文件单独无效（请求名不含后缀）。

## 实机验证

✅ v0.56 菜单、HUD、暂停界面全部恢复。

## 可迁移的方法

1. 先确认 UI 是 SWF 渲染还是自绘
2. 找到"判断是否需要加载"的门控
3. 观测门控调用顺序推断结果，不额外调用
4. 名字比较失败优先检查后缀/前缀/大小写
