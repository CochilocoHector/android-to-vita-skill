# 真实案例

每个案例必须包含 7 个部分：

```
问题现象 → 初始假设 → 静态证据 → 排除的错误假设 → 根因 → 最小修复 → 实机验证结果
```

## 状态判定

| 标记 | 条件 |
|---|---|
| ✅ 成功案例 | 静态证据成立 **且** 实机验证通过 |
| ◐ 已实现未验证 | 代码已改、构建完成，但**尚未实机确认** |
| ☐ 仅分析 | 只定位到原因，未实现 |

**未经实机验证的修复不得标记为成功案例。**
